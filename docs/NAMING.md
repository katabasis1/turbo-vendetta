## 2. Требования к нашему названию
1. Бренд из 1–2 слов, одинаково читается по-русски и по-английски — лучше из международных слов (турбо, нитро, нокаут, дуэль, вендетта, хром).
2. Про суть игры: соперники, реванш, тараны, скорость.
3. Свободно как название игры в Steam, itch.io, Google Play, CrazyGames, Яндекс Играх; нет известной игры/события с таким именем.
4. Подзаголовок с ключом жанра для каталога, меняется по площадкам.
5. Без «Онлайн» в названии: у нас асинхронный PvP, формулировка может считаться вводящей в заблуждение.
