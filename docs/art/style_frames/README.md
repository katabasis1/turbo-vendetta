# Кадры стиля — этап 0.3

Мокапы для согласования стиля «Аниме-аутран 90-х» / «Закатная трасса» (D-006 + D-012). В игру не идут. Правила — `docs/STYLE_GUIDE.md`.

| Файл | Экран | Как сделан |
|---|---|---|
| `frame_01_track.jpg` (960×540) | трасса: дрифт, таран босса, HUD | офлайн-рендер черновых моделей (Python, cel-shading 3 ступени) + 2D-слой HUD |
| `frame_02_garage.jpg` (960×540) | гараж | то же |
| `frame_03_results.jpg` (1920×1080) | итоги заезда | 2D-слои в палитре гайда + вырезка машины из `wip/cars2.jpg`; скрипт `src/frame_03_results.py` |
| `../palette.png` | лист палитры | `src/palette_sheet.py` |

`wip/` — промежуточные итерации кадра трассы (`t1b`…`t1e`), черновые модели машин (`cars2`), проба шрифтов (`fonts`).

⚠ Скрипт рендера кадров 1–2 (сессия 2026-10-25, ночь) не был сохранён в Pod и утерян вместе с песочницей. Остались только картинки. Правило с 2026-10-25: исходник любого артефакта сохраняется в Pod (`src/`) в том же чекпоинте.

Запуск: `python3 docs/art/style_frames/src/frame_03_results.py docs/art/style_frames/wip/cars2.jpg docs/art/style_frames/frame_03_results.jpg`. Нужны Pillow, numpy, scipy и шрифты Noto (есть в Computer).
