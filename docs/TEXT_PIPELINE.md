# TEXT_PIPELINE.md — как текст попадает в игру

> Решение D-010. Действует для всех текстов игрока: интерфейс, обучение, реплики боссов, задания, описания машин, тексты каталога Яндекс Игр, сообщения об ошибках.

## Где живут строки
- `localization/strings.csv`, колонки: `keys,ru,en,_status` (подчёркивание обязательно: Godot пропускает колонки с `_` в начале, а `status` принял бы за язык — D-015). В сценах и коде — только ключи (`tr("UI_RACE_AGAIN")`, у `Label` — ключ в `text`).
- Ключи: `ОБЛАСТЬ_СМЫСЛ` латиницей в верхнем регистре: `UI_`, `HUD_`, `TUT_`, `BOSS_<имя>_`, `CAR_<id>_`, `QUEST_`, `STORE_`, `ERR_`.
- Подстановки — только именованные: `{place}`, `{time}`, `{coins}`. Теги BBCode допустимы в `RichTextLabel`.
- Статусы: `draft` → `humanized`. Для правки после очеловечивания статус снова `draft`.

## Шаги для каждой новой или изменённой строки
1. **Черновик.** Пишем смысл, задаём длину под место в UI (см. «Лимиты»). Статус `draft`.
2. **Очистка.** Если текст вставлен из чата: `python3 docs/skills/humanizer-ru/scripts/clean_paste.py файл.txt`.
3. **Русский.** Правка по `docs/skills/humanizer-ru/SKILL.md` (+ `references/patterns.md`). Для пачки строк — выгрузить колонку `ru` в txt, править целиком, вернуть.
4. **Английский.** Правка по `docs/skills/humanizer-en/SKILL.md`. Английский пишется как самостоятельный текст, а не подстрочник русского.
5. **Сверка фактов.** `python3 docs/skills/humanizer-ru/scripts/check_facts.py до.txt после.txt` — числа, имена, подстановки не должны поменяться. Для английского — ручная сверка подстановок.
6. **Проверка валидатором** (`tools/validate.py`, этап 1.1): у каждой строки есть ru и en; набор подстановок `{...}` в ru и en совпадает; ключи из сцен и кода существуют в CSV; в релизной сборке нет `draft`.
7. Статус `humanized`, запись в PROGRESS.md (какие ключи прошли).

## Правила для коротких строк интерфейса
Навыки рассчитаны на прозу, а у нас много подписей в 1–3 слова. Для них:
- Глагол и прямое действие: «Ещё заезд», «Забрать», «В гараж». Не «Повторить попытку прохождения».
- Без канцелярита и пустых слов: не «Осуществляется загрузка» → «Загрузка…».
- Восклицательный знак — только в событиях гонки (обгон, такдаун, рекорд), не на кнопках.
- Обращение на «ты» во всей игре (casual-аудитория Яндекс Игр, в том числе дети). Если в STYLE_GUIDE решим иначе — меняем здесь.
- Капслок — только стилем шрифта в HUD, в CSV текст пишется обычным регистром.
- Кнопка с рекламой обязана сказать, что будет реклама и что за неё дадут (п. 4.5.1 требований): «Смотреть рекламу: ×2 монеты».

## Лимиты (стартовые значения)
| Место | Лимит ru/en | Как проверить | Куда крутить |
|---|---|---|---|
| Кнопка | ≤ 18 символов | скриншот 360×640 (телефон) | шире кнопка или короче текст |
| Заголовок экрана | ≤ 24 | то же | размер шрифта |
| Всплывашка в гонке | ≤ 14 | читается за 0,5 с на телефоне | короче слово, иконка вместо слова |
| Строка обучения | ≤ 70 | читается за 3 с | разбить на 2 шага |
| Описание в каталоге Яндекса | по правилам консоли | сверка с требованиями | — |

Русский обычно на 15–30% длиннее английского: верстаем под русский.
