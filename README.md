# Турбовендетта: гонки на выбывание / Turbo Vendetta: Knockout Racing

3D аркадная гонка с автобоями для Яндекс Игр. Godot **4.7.2**, рендерер **Compatibility** (WebGL 2), GDScript.

## Как открыть
1. Godot 4.7.2 (стандартная сборка, не .NET).
2. «Импорт» → выбрать `project.godot` → дождаться импорта.
3. F5 — запуск (`scenes/boot/boot.tscn`).

## Изменения от агента
Агент присылает пакет `turbo-vendetta_changes_ГГГГММДД-ЧЧММ.zip` (+ `.patch` и `.txt`). Распаковать поверх репозитория и закоммитить (или `git apply …patch`); что удалить вручную — в `.txt`. Подробно — `AGENTS.md`, «Источник истины».

## Сборки
- **Web** — релиз, без `scenes/dev/`. Однопоточная (`thread_support = false`), как требует Яндекс Игры.
- **Web (спайки)** — то же + сцены технических проверок `scenes/dev/spikes/` (признак `spikes`: boot открывает меню спайков). Порядок проверки — `docs/SPIKES.md`.

## Правила кода (коротко)
Композиция вместо наследования, узлы не создаются кодом (только `instantiate()` готовых сцен в белом списке), строгая типизация, тексты — ключи из `localization/strings.csv`. Проверка: `python3 tools/validate.py`.
